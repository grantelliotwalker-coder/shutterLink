INSTAGRAM POST TILES (parked feature)
=====================================

Removed from the live code on 19 Nov 2026. Kept here in case we pick it up again.

What it did
-----------
- Settings > Instagram tab: "Connect Instagram" (a demo account with 12 sample
  posts), or "Use your real posts now" by pasting an access token generated in
  the Meta App Dashboard (professional accounts only; dashboard tokens last 60 days).
- Pick up to 12 posts. Each became a tile on the link page with its photo and
  caption, under a "From Instagram" section. Captions were editable, and each
  tile could carry its own button link (e.g. "Buy this print").
- Tapping a tile opened a sheet with the full photo, caption, date, the custom
  button and "View on Instagram".
- A "Posts" quick-button action jumped to the tiles.
- The token was stored only in the browser (never in the page config or backups).

What the live version needs
---------------------------
- A Meta app using Instagram API with Instagram Login (Business Login).
- A Sport Shutter server step to swap the login code for a long-lived token
  (this must be server side), plus a job to refresh it before 60 days.
- Server-side copies of chosen images, because Instagram image links expire.
- API call used: GET https://graph.instagram.com/me/media
  ?fields=id,caption,media_type,media_url,thumbnail_url,permalink,timestamp

How to bring it back
--------------------
Easiest: the original commit is 883f016 on main.
  git cherry-pick 883f016
(Expect small conflicts in the ?v= version numbers on the core.js script tags;
keep the newer number.)

Or apply the patch below from the repo root (the 3-way option handles the
version-number lines that have changed since):
  sed -n '/^=== PATCH START ===$/,$p' notes/instagram-tiles.txt | tail -n +2 > /tmp/ig.patch
  git apply --3way /tmp/ig.patch
